AI Literacy Quiz Platform
About the project

I am rebuilding my AI Literacy Quiz Platform from scratch to learn TypeScript and improve my full-stack development skills.

Researchers can create quizzes containing images, and visitors can take quizzes to guess whether the images are AI-generated or human-created.

Tech stack
Frontend: React, TypeScript, Vite
Backend: Node.js, Express, TypeScript
Database: MongoDB, Mongoose
Tools: Git, GitHub, Swagger, Storybook
Project scope
Core features
Visitors can browse and take quizzes.
Visitors can view their results.
Researchers can register, log in and log out.
Researchers can create, edit, delete and publish quizzes.
Researchers can view their quizzes and basic statistics.
Researchers can only manage their own quizzes.
The application handles loading states and errors.
Later improvements
Email verification and password reset.
Secure authentication with HttpOnly cookies and refresh tokens.
Demographic questions and more detailed analytics.
Email results to participants.
API documentation with Swagger.
Component documentation with Storybook.
